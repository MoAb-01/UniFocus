## 🚀 Başlarken

### 1. Açık Kayıtları (Issues) İnceleyin
- `good first issue` veya `help wanted` etiketli açık [GitHub Kayıtları](https://github.com/MoAb-01/unifocus/issues) arasından bir görev seçin.
- Üniversitenize özel yeni bir not baremi veya mola mini oyunu eklemek mi istiyorsunuz? Kod yazmaya başlamadan önce bir **Feature Request** (Özellik Talebi) açın.

### 2. Yerel Geliştirme Ortamı Kurulumu

1. Projeyi klonlayın:
```bash
git clone [https://github.com/MoAb-01/unifocus.git](https://github.com/MoAb-01/unifocus.git)
cd unifocus
```

2. Flutter paketlerini yükleyin:
```bash
flutter pub get
```

3. Uygulamayı çalıştırın:
```bash
flutter run
```

---

## 🔄 Çekme İsteği (PR) Kuralları

1. Açıklayıcı bir dal (branch) oluşturun:
```bash
git checkout -b feat/ozellik-adiniz
```

2. Kod kalitesini ve biçimlendirmeyi denetleyin:
```bash
dart format .
flutter analyze
```

3. Anlaşılır commit mesajları kullanın:
- `feat: yeni mola oyunu eklendi`
- `fix: AKTS hesaplama hatası düzeltildi`
- `docs: kurulum adımları güncellendi`

4. Dalınızı gönderin ve `main` dalına bir Pull Request açın. Görsel değişiklikler için ekran görüntüsü veya GIF ekleyin.
