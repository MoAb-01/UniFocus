## 🚀 Getting Started

### 1. Explore Issues
- Check open [GitHub Issues](https://github.com/MoAb-01/unifocus/issues) labeled `good first issue` or `help wanted`.
- Want to add a new university grade matrix or study mini-game? Open a **Feature Request** issue first so the design can be aligned before writing code.

### 2. Local Environment Setup

1. Clone the repository:
```bash
git clone [https://github.com/MoAb-01/unifocus.git](https://github.com/MoAb-01/unifocus.git)
cd unifocus
```

2. Install Flutter dependencies:
```bash
flutter pub get
```

3. Run the application:
```bash
flutter run
```

---

## 🔄 Pull Request Guidelines

1. Create a descriptive feature branch:
```bash
git checkout -b feat/your-feature-name
```

2. Verify code quality and static analysis:
```bash
dart format .
flutter analyze
```

3. Commit changes with clear conventional prefixes:
- `feat: add new break mini-game`
- `fix: correct ECTS credit recalculation bug`
- `docs: update setup steps`

4. Push the branch and submit a Pull Request to `main`. Include screenshots or brief GIFs for any visual interface updates.
